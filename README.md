# Browser Tools

Browser Tools provides browser automation, debugging, Chrome DevTools helpers, persistent Chrome profile control, and Camoufox anti-detect browsing.

## Development

```bash
uv sync
uv run browser-tools --help
uv run pytest
```

Runtime browser automation may require Chrome/Chrome Canary, Node.js for `chrome-devtools-mcp`, and Camoufox for anti-detect Firefox workflows.
