# Agent rules

Repeat-mistake rules for this repository, each paired with the check that
enforces it. A rule a check enforces stays out of `AGENTS.md`: the check's
error teaches it. Add a row when a mistake class is fixed at the enforcement
level, and drop the row once its mistake cannot happen.

| Rule | Enforced by | First occurrence |
| --- | --- | --- |
| When the Python caller stops using an entry point of the injected JS helper (`login_form.js`), delete the JS declaration, its export, and its contract-comment entry in the same change. The helper's exports must stay exactly the entry points `login.py` still references as `__btLogin.<name>` **call strings** (derived from login.py's AST: only string literals passed to `_eval_login_script` count, never comments, docstrings or diagnostic strings); success polling is standalone Python and is never a helper entry point. | `tests/test_login_live.py::TestBridgeContract::test_helper_exports_match_the_python_caller` (fails naming each unused export and instructing removal) and `test_a_seeded_comment_or_docstring_mention_is_not_a_use` (seeded prose and diagnostic mentions cannot legitimize an export) | Round-two review, Quality Q4 and Reuse: the round-one polling rewrite left `probe` exported with no caller. Round-three B6: a comment mention could satisfy the old regex guard. |
| Provider startup failures produce fixed relay diagnostics without the operating-system error text, including the missing-binary case, whose cause is suppressed like every other spawn `OSError`. | `tests/test_credential_relay.py::TestMissingAndUnsupportedBinaries::test_an_unspawnable_binary_is_one_fixed_operational_error` and `test_an_injected_oserror_is_normalized_without_its_text` | The startup path in `869fdd6` let `OSError` escape the diagnostic boundary. Round-three B7 found the `FileNotFoundError` cause still attached. |
| The APPROVED LOGINS manual must state the recorded physical-owner contract (usable debug port, user-data directory, start-time identity, a running process of ours holding the directory, refusal before opchain is asked for anything, unnamed instances qualifying) and its operation order: recorded owner, no-value capability probe, page session, connected-browser identity before any credential field is read, document validation, credential reads. The connected-browser check never precedes the probe or the attach. | `tests/test_guide.py::TestApprovedLoginContract::test_the_recorded_owner_contract_is_documented` and `test_the_documented_order_matches_the_operation` (each failure names the missing phrase or the contradicted order) | Round-three review, Tests T9 (deleting the ownership paragraph left the guide proof green) and T10 (the documented refusal order was wrong). |
