# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

- **Do NOT open a public GitHub issue.**
- Email: kevinfrilot@icloud.com
- Include a description of the vulnerability, steps to reproduce, and potential impact.

You will receive a response within 48 hours. If the vulnerability is confirmed, a fix will be prioritized and a security advisory published.

## Disclosure

- We follow coordinated disclosure.
- Please allow reasonable time for a fix before any public disclosure.
